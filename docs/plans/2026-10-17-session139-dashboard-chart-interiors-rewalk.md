## The walk-harness lessons

- **L-139c1 the card-class locator trap**: the dashboard's Card is `rounded-xl`,
  not `rounded-lg` — the first walk run's class-selector locators silently no-op'd
  (the tooltip + round-trip + containment sections). The title-text CLIMB
  (border+shadow) is the class-agnostic finder; every census section must use it.
- **L-139c2 the inactive-tooltip-wrapper trap**: every recharts chart keeps its
  tooltip wrapper mounted in the DOM showing the INITIAL data point's state — a
  bare `querySelector('.recharts-tooltip-wrapper')` reads the FIRST chart's stale
  wrapper, not the hovered chart's live one. Scope the read to the hovered chart's
  card (a data-attribute mark) + the visibility filter.
- **L-139c3 the random-mask discipline**: number-masking tooltip texts for the
  two-app diff HID the value-form distinction (integer vs decimal) the raw record
  exposes — record BOTH; the mask proves the structure, the raw carries the form.
- **L-139c4 the trailing-zero trim**: toLocaleString's 3-fraction-digit default
  trims trailing zeros — a 2-decimal display ("$57,824.88") can mask a raw float;
  characterize random faces across N samples before concluding quantization.
